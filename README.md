# Spla Experiments

Репозиторий предназначен для проведения экспериментов по сравнению производительности библиотек [Spla](https://github.com/SparseLinearAlgebra/spla) и [LAGraph](https://github.com/GraphBLAS/LAGraph) при выполнении алгоритмов анализа графов. Для запуска бенчмарков используется [Graph-bench](https://github.com/EgorOrachyov/graph-bench).

В рамках экспериментов сравнивается время выполнения алгоритмов BFS, SSSP, PageRank и Triangle Counting на выбранных графах.

## Требования

- **ОС:** Linux.
- **Инструменты сборки:** CMake 3.20+, GCC/G++ 9+, Ninja, GNU Make.
- **Python:** Python 3 с поддержкой `venv` и `pip`.
- **Дополнительные инструменты:** Git, `unzip`.
- **Вычислительное устройство:** GPU с поддержкой OpenCL и совместимый драйвер.

## Быстрый старт

### 1. Загрузка репозитория

Клонируйте репозиторий и перейдите в каталог со скриптами:

```bash
git clone https://github.com/Lintari/Spla_experiments.git
cd Spla_experiments/src
```

### 2. Подготовка окружения

Запустите скрипт подготовки:

```bash
bash setup.sh
```

Скрипт загрузит Graph-bench и его подмодули, соберёт необходимые библиотеки, скачает датасеты и подготовит данные для проведения экспериментов.

### 3. Запуск экспериментов

Запустите скрипт, указав имя графа:

```bash
sudo bash run.sh cit-Patents
```

Вместо `cit-Patents` укажите имя графа из используемого датасета.

Скрипт выполняет 20 запусков бенчмарка для сравнения Spla и LAGraph. Перед каждым измерением очищается файловый кэш операционной системы.

Для выполнения команды требуются права суперпользователя: они используются для очистки кэша. При этом скрипт запускает сами измерения от имени исходного пользователя.

## Используемые проекты

- [Graph-bench](https://github.com/EgorOrachyov/graph-bench) — запуск бенчмарков и измерение производительности.
- [Spla](https://github.com/SparseLinearAlgebra/spla) — библиотека разреженной линейной алгебры с поддержкой OpenCL.
- [LAGraph](https://github.com/GraphBLAS/LAGraph) — библиотека алгоритмов анализа графов на основе GraphBLAS.
